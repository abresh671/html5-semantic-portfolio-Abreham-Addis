## 1. Project Description
This repository contains a single-page static developer portfolio built strictly using pure **HTML5 semantic markup**. The goal of this project is to construct a well-formed, accessible, and resilient web page using native HTML elements, landmarks, interactive controls, and proper document structure without relying on any CSS or JavaScript frameworks.

## 3. Implemented Semantic Elements

Here is the complete list of semantic HTML5 elements used throughout the project:

* **Page Landmarks:** `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
* **Content Structure & Grouping:** `<article>`, `<aside>`, `<hgroup>`, `<figure>`, `<figcaption>`
* **Text & Data Semantics:** `<time>`, `<mark>`, `<address>`, `<dl>`, `<dt>`, `<dd>`
* **Media Elements:** `<img>`, `<video>`, `<source>`, `<track>`
* **Interactive Elements:** `<details>`, `<summary>`, `<dialog>`
* **Form & Controls:** `<form>`, `<fieldset>`, `<legend>`, `<label>`, `<input>`, `<select>`, `<textarea>`, `<button>`
